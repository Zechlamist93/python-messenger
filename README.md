# 💬 Python Messenger

A lightweight, Flask-based instant messaging blueprint featuring a local database implementation, user handling, and a clean web interface.

Eine leichtgewichtige Web-Chat-Anwendung auf Flask-Basis inklusive eigener Datenbank-Anbindung und Benutzeroberfläche.

---

## 🌟 Key Features

- **Flask Blueprint Architecture:** Modularly integrated as a standalone blueprint into a web application.
- **Database Integration:** SQLite backend with automatic database initialization (`init_db()`).
- **Responsive Web UI:** Simple and clean browser UI for real-time interaction.
- **Privacy-First Design:** Self-hosted solution running without third-party tracking or mandatory cookies.
